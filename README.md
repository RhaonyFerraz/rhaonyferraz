### Projetos em Destaque

- **[SAP BTP — Portal de Logística & Estoque RF](https://github.com/RhaonyFerraz/sap-portal-estoque)**  
  Solução de borda que otimiza custos com licenças SAP ERP (~US$ 82.200/ano para 50 operadores). Integração via OData V4 com SAP HANA, Service Binding RAP, fila offline com auto-sync e decodificador GS1-128 / DataMatrix.  
  *Aplicação no ar:* [rhaonyferraz.github.io/sap-portal-estoque](https://rhaonyferraz.github.io/sap-portal-estoque/)

- **[Carga & Validação de Clientes via Excel (ABAP Cloud)](https://github.com/RhaonyFerraz/cadastro-excel-abap)**
